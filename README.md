# Cut Local Studio

한국어 로컬 영상 편집기입니다. 유료 API, 계정, 워터마크 없이 FFmpeg, Demucs, faster-whisper를 사용합니다. CapCut의 사용 흐름을 참고한 독립 앱이며 CapCut의 코드·상표·유료 에셋을 포함하지 않습니다.

## 실행

1. **실행.cmd**를 더블클릭합니다. Node.js가 필요하며, 첫 실행에서 무료 패키지와 FFmpeg를 다운로드합니다.
2. 브라우저에서 `http://127.0.0.1:4310`을 엽니다.
3. 영상·오디오 여러 개를 불러오거나 드래그한 뒤, 미디어의 **＋**를 눌러 타임라인에 추가합니다.
4. 컷을 선택해 편집하고 **내보내기 → MP4 영상 저장**을 누릅니다.

브라우저 자동 저장 외에 **저장**으로 `.cutlocal` 프로젝트 파일을 받을 수 있습니다. 프로젝트 파일은 미디어를 포함하지 않으며, 다른 PC로 옮길 때 이 폴더의 `.data`도 함께 복사해야 합니다. 내보낸 MP4는 `.data/exports`에도 보관됩니다. 서버는 이 PC의 루프백 주소에만 바인딩됩니다.

## 편집

- 미디어: 다중 불러오기, 파일 드롭, 영상/오디오 필터, Del 제거, 사용 중인 컷 삭제 확인, 미사용 미디어 정리. 제거는 프로젝트 참조만 지우며 디스크 파일은 보존합니다.
- 컷: `S`로 재생 위치 분할, `C` 칼 도구 클릭 분할, `V` 선택 도구, 양끝 손잡이 트림, 숫자로 원본 시작/끝 입력, 삭제·복제, 드래그/앞뒤 버튼 순서 변경, 실행 취소/다시 실행, 좌우 방향키 프레임 이동, 0.25~4배속.
- 화면: 원본·16:9·9:16·1:1·4:3, 전체 보기/채우기, 미리보기 드래그 이동, 손잡이·숫자·버튼으로 1~400% 확대, 가운데 정렬·초기화, 90도 회전·좌우 반전, 출력 픽셀 표시.
- 소리: 원본 마스터와 컷별 음량, 음소거, 추가 음원 개별 음량/시작 시각/원본 시작 위치/반복/길이, 원본 음성 싱크, 시작·끝 페이드, 실제 추출한 파형.
- 자막: 영상 음성을 로컬 AI로 인식, 언어 자동 감지·한국어·영어·일본어·중국어, 빠르게/균형/정확하게 모델, 문장·시작·끝 직접 수정, 글자 크기·위치·색·배경 조절, 직접 추가·개별/전체 삭제, SRT 저장, 미리보기, MP4에 자막 입히기.
- 단축키: Space 재생, Ctrl+Z 취소, Ctrl+Shift+Z 또는 Ctrl+Y 다시 실행, Ctrl+D 복제, Ctrl+S 프로젝트 저장.

## AI 자동 자막

1. **AI-설치.cmd**를 한 번 실행합니다.
2. 음성이 있는 영상을 불러와 타임라인에 추가합니다.
3. 화면 위쪽의 **AI 자막** 버튼을 누릅니다.
4. 원본·언어·정확도를 선택하고 **자막 자동 생성**을 누릅니다.
5. 각 문장과 시작·끝 시간을 수정하고, 스타일을 정한 뒤 **적용하고 닫기**를 누릅니다.
6. 별도 자막 파일은 **SRT 저장**, 영상에 고정된 자막은 **내보내기**를 사용합니다.

faster-whisper가 CPU에서 음성을 인식합니다. 첫 사용에는 선택한 무료 모델을 `.data/whisper-models`에 다운로드하므로 인터넷이 필요합니다. 이후 같은 원본·언어·모델 조합은 `.data/subtitles`의 결과를 재사용하며 외부 API로 영상을 전송하지 않습니다. `빠르게(tiny)`는 속도 우선, `균형(base)`은 기본값, `정확하게(small)`는 품질 우선이며 CPU 처리 시간이 더 깁니다. 원본 30분 이하를 지원합니다.

## 목소리·배경음악 분리

**AI-설치.cmd**를 한 번 실행합니다. 프로젝트 전용 Python 3.11(사용 가능한 번들 Python은 3.12), CPU용 PyTorch, Demucs 4.0.1, faster-whisper 1.2.1이 설치됩니다. 설치와 최초 모델 다운로드에 인터넷이 필요하며 수 GB의 여유 공간을 권장합니다. 설치 이후 미디어를 서버로 업로드하지 않고 PC에서 처리합니다.

소리가 있는 미디어 또는 영상 컷을 선택하고 **목소리와 배경음악 분리**를 누릅니다. 두 결과의 미리듣기와 WAV 저장이 가능하고, 영상 컷에서 별도 음량·목소리만·음악만을 선택한 뒤 적용할 수 있습니다. 동일 내용의 원본은 SHA-256으로 식별하여 기존 결과를 재사용합니다. CPU로 한 번에 한 건 처리하며 원본 30분 이하를 지원합니다. 처리 시간과 분리 품질은 CPU·음원에 따라 달라집니다.

## 저장 및 기술적 범위

- 원본을 `.data/media`로 복사하고 편집용 H.264/AAC 프록시와 파형을 만듭니다. 긴 영상은 초기 준비 시간이 필요합니다. 원래 위치의 파일은 변경하거나 삭제하지 않습니다.
- MP4 내보내기는 원본에서 FFmpeg H.264/AAC로 렌더링합니다. 선택 비율은 1080p 기본, 원본 비율은 원본 해상도를 사용하며 최대 4096px입니다.
- 브라우저 미리보기는 편집용 프록시와 HTML 미디어 재생을 사용합니다. 타임라인의 프레임 이동은 선택 FPS 기준이며 브라우저 디코더에 따라 프레임 탐색/컷 전환에 약간의 지연이 생길 수 있습니다. 최종 출력은 FFmpeg로 처리합니다.
- 비디오 1개 순차 트랙과 여러 오디오 레이어를 지원합니다. 여러 오디오 레이어는 세로로 배치되며 겹치는 구간은 함께 믹싱됩니다. 전환 효과와 다중 비디오 합성은 이번 범위에 포함되지 않습니다.
- 음성 싱크 + 값은 소리를 앞당깁니다. 위치 X/Y는 출력 화면 크기 대비 %. 추가 음원은 지정한 원본 시작 위치부터 끝까지 반복합니다.
- 종료는 작업 관리자에서 해당 `node server.mjs` 프로세스를 종료하거나, `npm start`로 직접 실행했다면 Ctrl+C를 누릅니다.

## 개발 및 검증

```powershell
npm install
npm start
npm test
npm run setup:ai
```
